`$ ip [опции] объект команда [параметры]`

**[ping]**

Для проверки связи между узлами сети (протокол ICMP).

Для IPv4: `$ ping <ip address>/<доменное имя>`
Для IPv6: `$ ping6 <ip address>/<доменное имя>`
Пинг-флуд: `$ ping -f losst.pro`

**Что означает параметр, который контролируется ключом -t?**
`$ ping -t 70 ya.ru` — устанавливает TTL (Time To Live) — время жизни пакета в сети.

**Какие существуют таблицы в iptables? Какой порядок обработки входящего трафика?**

- `mangle` — для модификации пакетов
- `nat` — для NAT
- `filter` — для фильтрации (по умолчанию)
