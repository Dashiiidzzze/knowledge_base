**[sources.list]**

Файл `/etc/apt/sources.list` содержит список источников, откуда APT скачивает пакеты.

**[/etc/passwd]**

Содержит информацию о пользователях. Каждая строка — один пользователь, поля разделены двоеточием.
![[image54.png]]
![DHCP](https://github.com/Dashiiidzzze/knowledge_base/blob/master/media/image54.png)

**Что значит строка /usr/sbin/nologin в содержимом файла?** — запрет входа в систему для данной учетной записи.

**[/etc/shadow]**

Хранит зашифрованные пароли пользователей и дополнительные свойства, связанные с паролем.
![[image55.png]]
![DHCP](https://github.com/Dashiiidzzze/knowledge_base/blob/master/media/image55.png)

**Что показывает файл? Чем отличается от /etc/passwd?** — в `/etc/shadow` хранится зашифрованный пароль, в `/etc/passwd` — остальная информация о пользователе.
![[image56.png]]
![DHCP](https://github.com/Dashiiidzzze/knowledge_base/blob/master/media/image56.png)

**[/etc/sudoers]**

Определяет, какие пользователи могут запускать команды sudo.
![[image57.png]]
![DHCP](https://github.com/Dashiiidzzze/knowledge_base/blob/master/media/image57.png)

**Как можно редактировать файл? А как его редактировать безопасно?**
Специальная команда `visudo` — при сохранении проверяет синтаксис. Для смены редактора: `$ sudo update-alternatives --config editor`

**Задача: настроить виртуальный интерфейс, который будет слушать трафик в 111 vlan-e.**
```
network:
    version: 2
    renderer: networkd
    ethernets:
        ens3: {}
    vlans:
        vlan5:
            id: 5
            link: ens3
            dhcp4: false
            addresses: [10.0.0.15/24]
            gateway: 10.0.0.1
```

**[/var/log/syslog]**

Глобальный системный журнал.

**Что показывает файл? Как туда что-нибудь записать?**
Все сообщения от механизма авторизации (кроме связанных с авторизацией) записываются в `/var/log/syslog`.
