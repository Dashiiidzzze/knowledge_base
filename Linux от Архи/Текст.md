# 4. Текст

**Абсолютный путь** — путь от корня системы (от `/`). Пример: `/dir/home/file.txt`
**Относительный путь** — путь относительно текущего местоположения. Пример: `./file.txt`

**[wc]**

`$ wc` — ждет ввода, выводит кол-во строк, слов, символов
`$ wc <имя файла>` — для файла

**Что покажет команда "lsof | wc"?** — сумму строк, слов и символов во всех используемых процессами файлах.

**[grep]**

`$ grep "шаблон" <файл>` — поиск строк с заданными символами

**Что делают ключи -C, -B, -A, -v?**
- `-C` — показать n строк до и после вхождения
- `-B` — показать вхождение и n строк перед ним
- `-A` — показать вхождение и n строк после него
- `-v` — вывести строки, где шаблон не найден

**[cat]**

`$ cat <имя файла>` — вывести содержимое файла полностью

**Что будет, если запустить команду без аргументов?** — все введенные символы будут перенаправляться в поток вывода.

**[vi/nano]**

Использование редактора VIM (3 режима):

*Command режим* (по умолчанию):
- `u` — отмена
- `shift + g` — переход в конец файла
- `r + [символ]` — замена одного символа
- `x` — удаление символа
- `d + d` — удаление строки
- `p` — вставить
- `/[искомое]` — поиск

*Insert режим*: `shift + a` (вход), `esc` (выход)

*Last line режим*: `shift + :` (вход), `esc` (выход)
- `:w` — сохранить
- `:q` — выход
- `:q!` — выход без сохранения
- `:wq` или `:x` — сохранить и выйти
- `:set number` — нумерация строк
- `:split [имя файла]` — горизонтальное разделение окон
- `:vsplit [имя файла]` — вертикальное разделение окон

**[less]**

`$ less <имя файла>` — вывод файла с возможностью прокрутки

**Когда полезно применения команды? Какие есть альтернативы?** — полезно для больших файлов. Аналог: `more <имя файла>`.

**[sed]**

Основные функции:
1. **Поиск и замена**: `sed 's/старый/новый/'`
2. **Удаление строк**: `sed '/pattern/d'`
3. **Извлечение строк**: `sed -n '/pattern/p'`
4. **Вставка текста**: `sed '/pattern/i Новый текст'`

**Задача: вывести текущий ip-адрес без маски сети**
```bash
ip addr show | grep 'inet ' | sed -n 's/[^0-9]*\([0-9.]\+\).*/\1/p'
```
