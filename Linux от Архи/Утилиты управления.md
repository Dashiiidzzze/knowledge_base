**[apt]**

*Утилита apt* (от англ. Advanced Package Tool) — это специальная надстройка на интерфейс командной строки, позволяющая удобно работать с системой управления пакетами dpkg. А именно — искать их, скачивать, обновлять, удалять и т.п.

`$ sudo apt update`
Вывод этой команды на экран включает данные о доступных пакетах, полученные от различных серверов.
![[image10.png]]
![DHCP](https://github.com/Dashiiidzzze/knowledge_base/blob/master/media/image10.png)

1. Hit — доступных обновлений для данного пакета сейчас нет
2. Ign — данный пакет игнорируется, так как его нельзя проверить или при проверке обновлений возник тривиальный сбой
3. Get — доступна для скачивания более новая версия пакета

`$ sudo apt upgrade`
![[image11.png]]
![DHCP](https://github.com/Dashiiidzzze/knowledge_base/blob/master/media/image11.png)

**В чем состоят отличия между командами apt update и apt upgrade?**
Команда apt update — только обновляет актуальную базу данных с доступными для установки пакетами программного обеспечения. Команда apt upgrade приводит к обновлению установленного пакета до более актуальной версии. Для экономии времени: `$ sudo apt update && sudo apt upgrade -y` (опция -y позволяет не подтверждать обновление каждого пакета).

**Откуда команда apt знает, в каких репозиториях нужно искать пакеты?**
Команда apt знает благодаря файлу `/etc/apt/sources.list` и директории `/etc/apt/sources.list.d/`.
![[image12.png]]
![DHCP](https://github.com/Dashiiidzzze/knowledge_base/blob/master/media/image12.png)

**Как добавить новый репозиторий?**
В директории `/etc/apt/sources.list.d/` надо создать файл с именем репозитория и расширением `.list`, затем добавить в него репозиторий. Например, для браузера Chrome:
```bash
$ sudo vi /etc/apt/sources.list.d/google-chrome.list
deb http://dl.google.com/linux/chrome/deb/ stable main
```
По умолчанию система не может доверять сторонним репозиториям — нужно импортировать ключ:
```bash
$ wget -q -O - https://dl-ssl.google.com/linux/linux_signing_key.pub | sudo apt-key add -
$ sudo apt update
```

Команда `$ apt-add-repository` делает то же самое, добавляя репозиторий в `/etc/apt/sources.list`.

**[cron]**

*Cron* — это планировщик задач, используемый для выполнения задач в указанное время.
*Crontab* - команда, которая используется для управления планировщиком Cron.

`$ crontab` - создает файл crontab.

Каждая строка содержит шесть полей:
```
* * * * * command(s)
│ │ │ │ │
│ │ │ │ └── Day of week (0-7, Sunday=0 or 7)
│ │ │ └──── Month (1-12)
│ │ └────── Day of month (1-31)
│ └──────── Hour (0-23)
└────────── Minute (0-59)
```

*Параметры команды Crontab:*
- `-e` - редактирование или создание файла расписания
- `-l` - вывод содержимого расписания
- `-r` - удаление файла расписания
- `-u <user>` - работа с расписаниями конкретных пользователей

**[systemctl]**

Systemctl — системная утилита для управления службами или демонами в системах с systemd.

**За что отвечает утилита:**
1. Запуск и остановка служб
2. Перезапуск служб
3. Проверка состояния служб
4. Управление автозапуском служб

**Как пользоваться:**
- `systemctl start <service>` - запуск
- `systemctl stop <service>` - остановка
- `systemctl restart <service>` - перезапуск
- `systemctl reload <service>` - перезагрузка (без полной остановки)
- `systemctl status <service>` - проверка статуса
