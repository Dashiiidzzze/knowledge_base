**[ln]**

`$ ln опции файл_источник файл_ссылки`

Опции:
- `-d` - разрешить создавать жесткие ссылки для директорий
- `-f` - удалять существующие ссылки
- `-i` - спрашивать нужно ли удалять существующие ссылки
- `-P` - создать жесткую ссылку
- `-r` - создать символическую ссылку с относительным путем
- `-s` - создать символическую ссылку
![[image21.png]]
![DHCP](https://github.com/Dashiiidzzze/knowledge_base/blob/master/media/image21.png)

*Символическая ссылка* — это специальный файл, который является ссылкой на другой файл или каталог (ярлык). При удалении целевого файла ссылка останется, но будет указывать в никуда.
*Жесткая ссылка* — это отдельный файл, ссылка в котором ведет к одному участку жесткого диска.

**[tar]**

`$ tar опции архив.tar файлы_для_архивации` — архивация
`$ tar опции архив.tar` — распаковка

Опции: `-c` (create), `-u` (update), `-r` (append)

**Как заархивировать все файлы в директории в .tar.gz архив?**
```bash
tar -czvf archive_name.tar.gz /path/to/directory/
```
- `c` — создать новый архив
- `z` — сжать с помощью gzip
- `v` — выводить информацию
- `f` — указать имя файла

**Как обеспечить совместный доступ к ресурсу (файлу, папке) для нескольких пользователей?**
1. `sudo mkdir /home/Shared`
2. `sudo addgroup newgroup`
3. `sudo chown :newgroup /home/Shared`
4. `sudo adduser user1 newgroup`
5. Повторить для всех пользователей
6. Настроить права: `sudo chmod 0770 /home/Shared` и т.д.

**[chmod]**

`$ chmod опции права /путь/к/файлу`

*Три основных вида прав:* `r` (чтение), `w` (запись), `x` (выполнение)

*Категории пользователей:* `u` (владелец), `g` (группа), `o` (остальные)

*Права для пользователей:* 744, 755, 764, 777

**Что будет, если сделать chmod 777 filename?** — всем разрешено все.
**Что значат три семерки?** — одна 7 это rwx.
**Что будет, если сделать chmod g-x filename?** — у группы запрещается выполнение.

**[chown]**

`$ chown пользователь опции /путь/к/файлу`

`$ chown root ./dir1` — изменение владельца на root
`$ chown root:root ./dir2` — изменение владельца и группы

**Что значит chown nobody:nogroup filename?** — изменение владельца и группы на nobody и nogroup.

**[mv]**

`$ mv hehe.txt ./papka/papka2` — переместить файл в папку

**[sudo]**

`$ sudo опции программа параметры` — запуск программ с привилегиями суперпользователя
`$ sudo -u <user>` — выполнить от имени другого пользователя

**Как можно сделать пользователя привилегированным?**
- `$ sudo -i` — залогиниться под root
- `$ sudo usermod -aG sudo username` — добавить пользователя в группу sudo

**[su]**

`$ su [options] [-] [user]` — заменяет пользователя оболочки shell

**Чем отличается su от sudo?**
`su` позволяет изменить текущего пользователя терминала на другого. `sudo` выполняет команду от имени root пользователя.
