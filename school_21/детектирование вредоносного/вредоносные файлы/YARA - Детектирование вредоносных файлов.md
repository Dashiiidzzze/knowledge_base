## Комментарии
В правила могут включаться в комментарии, аналогичные комментариям в C. В правилах Yara можно использовать однострочные и многострочные комментарии.

```
/*     
This is a multi-line comment. 
*/ 

rule Example   // this is a single-line comment 
{     
	condition:        
	True 
}
```

## Условия

Условия — это не что иное, как логические выражения, которые можно найти во всех языках программирования, например, оператор _if_. Они могут содержать типичные логические операторы `and`, `or` и `not`, а также условные операторы `>=`, `<=`, `<`, `>`, `==` и `!=`. Кроме того, арифметические операторы (`+`, `-`, `*`, `\`, `%`) и побитовые операторы (`&`, `|`, `<<`, `>>`, `~`, `^`) могут использоваться в выражениях.

```
rule condition_Example 
{     
	strings:         
		$a = "text1"         
		$b = "text2"         
		$c = "text3"         
		$d = "text4"      
	
	condition:         
		($a or $b) and ($c or $d) 
}
```

## **Структура правила YARA:**

1. имя правила (`rule Example_Rule`) - Обязательная часть
2. секция `strings:` (определение строк) -  Необязательная часть
3. секция `condition:` (условие срабатывания) - Обязательная часть

**Секция строк (strings):**
- Каждая строка получает **идентификатор** — `$` + имя (буквы, цифры, подчеркивание)
- Строки могут быть:
    - **Текстовыми:** `$my_text_string = "text"`
    - **Шестнадцатеричными:** `$my_hex_string = { E2 34 A1 C8 23 FB }`
- Секцию можно **опустить**, если правило не ищет строки

**Секция условия (condition):**
- Определяет логику срабатывания правила
- Ссылается на идентификаторы строк (`$my_text_string`)
- **Обязательна** даже при отсутствии секции строк

**Пример из кода:**
```
rule Example_Rule 
{ 
	strings: 
		$my_text_string = "text" 
		$my_hex_string = { E2 34 A1 C8 23 FB } 
		
	condition: 
		$my_text_string or $my_hex_string 
}
```

- Правило `Example_Rule` сработает, если в файле найдена **либо** текстовая строка `"text"`, **либо** указанная шестнадцатеричная последовательность.
