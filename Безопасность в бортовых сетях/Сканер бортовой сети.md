Отлично, Дарья. Ваша задача — реализовать **контейнер "SecurityScanner"**, который будет **проверять открытые порты и потенциальные уязвимости конфигурации** у каждого другого контейнера, моделирующего элементы бортовой сети.

---

## 🛠 Что должен делать SecurityScanner:

1. **Пинговать каждый контейнер**.
    
2. **Сканировать открытые порты** (например, с помощью `nmap` или `socket` в Python).
    
3. **Проверять стандартные уязвимости конфигурации** (например, слабые HTTP-заголовки, открытые FTP, SSH без пароля и т.п.).
    
4. **Формировать отчёт**.
    

---

## 🔧 Как это организовать

1. Подключите SecurityScanner ко всем нужным сетям (`internal` и `public`) в `docker-compose.yml`.
    
2. Внутри скрипта укажите список хостов по именам контейнеров (Docker сам их резолвит).
    
3. Сканируйте порты через `nmap`, `socket`, `requests`.

## 🐍 Пример `scan.py`

```python
# scan.py — Сканирует контейнеры в сети Docker

import socket
import time

# Хосты и порты, которые сканируем
targets = {
    "avionics": [22, 80, 443],
    "pilot_interface": [80],
    "maintenance_server": [5000],
    "ife_server": [80],
    "secure_gateway": [443],
}

# Простая проверка подключения по сокету
def check_port(host, port, timeout=1):
    try:
        with socket.create_connection((host, port), timeout=timeout):
            return True
    except Exception:
        return False

# Запуск сканирования
def main():
    print("🛡 Начинаем сканирование контейнеров...\n")
    time.sleep(5)  # подождать, пока все контейнеры поднимутся

    for host, ports in targets.items():
        print(f"🔍 Проверка {host}:")
        for port in ports:
            result = check_port(host, port)
            status = "ОТКРЫТ" if result else "закрыт"
            print(f"  - Порт {port}: {status}")
        print()
    print("✅ Сканирование завершено.")

if __name__ == "__main__":
    main()
```
