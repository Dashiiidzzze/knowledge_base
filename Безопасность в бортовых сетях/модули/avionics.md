### Функциональность:

- Модуль действует как мост между UDP (эмуляция CAN-шины) и MQTT протоколами
- Принимает данные по UDP на порту 5005
- Обрабатывает полученные данные и публикует их в MQTT-топик avionics/data/#

### Уязвимости и проблемы взаимодействия:

1. **Отсутствие валидации входных данных**:
    - Принимает UDP-пакеты с любого источника без аутентификации
    - Проверяет только формат JSON, но не содержимое или структуру данных
    - **Уязвимый порт**: UDP 5005 (принимает любые данные)
2. **Отсутствие безопасности MQTT-соединения**:
    - Не использует аутентификацию для подключения к MQTT-брокеру
    - Не использует TLS/SSL для шифрования MQTT-трафика
    - **Уязвимая конфигурация**: MQTT без аутентификации на порту 1883
3. **Проблемы обработки ошибок**:
    - При ошибке соединения с MQTT только выводит предупреждение, но продолжает работу
    - UDP-приёмник запускается даже при проблемах с MQTT, что может привести к потере данных
