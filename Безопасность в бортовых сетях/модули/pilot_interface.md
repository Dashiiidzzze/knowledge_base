### Текущая функциональность:

- Предоставляет HTTP API на порту 80
- Имеет два эндпоинта:
    - `/telemetry` - возвращает статические данные о полете
    - `/command/<action>` - принимает команды, но только логирует их

### Проблемы и уязвимости:

1. **Отсутствие аутентификации:**
    - Нет проверки пользователя/пилота
    - API доступен без авторизации
    - **Уязвимость**: Любой может получить данные телеметрии и отправить команды
2. **Статические данные:**
    - Данные телеметрии захардкожены, нет реального подключения к модулю avionics
    - **Архитектурная проблема**: Нет интеграции с реальными системами
3. **Отсутствие обработки команд:**
    - Команды только логируются, не передаются в систему avionics или контроллеры
    - **Архитектурная проблема**: Нет реальной функциональности управления
4. **Небезопасное соединение:**
    - Использует HTTP вместо HTTPS
    - **Уязвимость**: Трафик может быть перехвачен
