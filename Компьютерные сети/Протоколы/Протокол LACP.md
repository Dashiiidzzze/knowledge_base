**Link Aggregation Control Protocol** — это стандартный протокол, который используется для объединения нескольких физических соединений в одно логическое. Это позволяет увеличить пропускную способность и обеспечить отказоустойчивость в сетях. LACP является частью IEEE 802.3ad и широко применяется в современных коммутаторах.

## Возможности и функционал LACP
LACP позволяет динамически управлять агрегацией каналов, что делает его более гибким по сравнению с другими методами агрегации, такими как статическая агрегация. Протокол автоматически определяет, включать или исключать порт из динамической агрегации. Если один из портов выходит из строя, LACP перенаправляет трафик через оставшиеся активные каналы.
### Возможности LACP
Увеличение пропускной способности: Объединение нескольких соединений позволяет достичь большей общей пропускной способности.
Отказоустойчивость: В случае сбоя одного из портов, трафик автоматически перенаправляется, что обеспечивает бесперебойную работу сети.
LACP упрощает управление агрегированными каналами, позволяя администраторам автоматически балансировать нагрузку между портами и отслеживать их состояние.

# **Настройка на коммутаторе**
**Подготовка интерфейсов**
```
conf t
interface FastEthernet1/14
switchport mode trunk
switchport trunk allowed vlan 1,10,20,1002-1005
channel-group 1 mode on                     # Ручная агрегация (без протокола, с протоколом - active вместо on)
exit

interface FastEthernet1/15
switchport mode trunk
switchport trunk allowed vlan 1,10,20,1002-1005
channel-group 1 mode on
exit
```

**Настройка Port-Channel**
```
interface port-channel 1
switchport mode trunk
switchport trunk allowed vlan 1,10,20,1002-1005
exit
end
```

**Как выключить и включить интерфейс**
shutdown - выключить, no shutdown - включить
```
enable
conf t
interface FastEthernet1/14
shutdown    
end
```
