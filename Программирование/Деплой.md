**Деплой (deployment)** — это процесс размещения Вашего приложения (например, контейнеров из Docker Compose) на целевой инфраструктуре (например, на сервере, виртуальной машине, в облаке), чтобы оно было доступно и работало в нужной среде.

Типичный деплой:
- вручную копировать файлы на сервер — устарело;
- запускать контейнеры — современный подход;
- через систему автоматизации — идеально.

## CI/CD

**CI (Continuous Integration)** — это автоматическая проверка, сборка и тестирование кода каждый раз при изменении (например, при `git push`).

**CD (Continuous Deployment/Delivery)** — это автоматический деплой:
- Continuous **Delivery** — развёртывание в staging среду (ручной перенос в продакшен).
- Continuous **Deployment** — всё автоматически до продакшена.

### Что включает базовая CI/CD цепочка?
1. **Контроль версий** — чаще всего Git (например, GitHub).
2. **CI/CD-сервер** — GitHub Actions, GitLab CI/CD, Jenkins, Drone CI, CircleCI и т.д.
3. **Инфраструктура** — VPS, облако (например, Yandex Cloud, AWS), или локальный сервер.
4. **Docker + Docker Compose** — для контейнеризации и управления окружением.
5. **Secrets (секреты)** — ключи, пароли, токены (например, через GitHub Secrets).
