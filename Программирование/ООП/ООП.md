**Объектно-ориентированное программирование (ООП)** — парадигма программирования, которая организует разработку программного обеспечения вокруг данных или объектов, а не функций и логики. Данные представляются как поля (свойства, атрибуты), а алгоритмы — как процедуры или функции (методы).

``` C++
class ClassName{	
	public:	…	
	
	protected:	…	
	
	private:	…
};
```

В секции **_public:_** объявляются свойства и методы доступные в самом классе, его потомках. Кроме того, можно обратиться к ним через объект класса, используя точечную запись: _имяОбъекта.свойтво/метод_. Объявление конструкторов, деструктора, переопределение операций должно располагаться в этой секции.

Секция **_private:_** содержит свойства и методы доступные только в определении методов этого класса.

### **Основные принципы ООП**
1. **Инкапсуляция (Encapsulation)**
	**Скрытие внутренней реализации и защита данных.**
	- Объединение данных и методов в одном классе.
	- Ограничение доступа к полям через модификаторы:
	    - `private` — доступ только внутри класса.
	    - `protected` — доступ в классе и наследниках.
	    - `public` — доступ откуда угодно.\

2. **Наследование (Inheritance)**
	**Создание новых классов на основе существующих.**
	- Дочерний класс (**наследник**) получает поля и методы родительского (**базового класса**).
	- Позволяет переиспользовать код и создавать иерархии.

3. **Полиморфизм (Polymorphism)**
	**Возможность объектов вести себя по-разному в зависимости от контекста.**
	- **Перегрузка методов** — несколько функций с одним именем, но разными параметрами.
	- **Переопределение методов** — замена метода родителя в наследнике.
	- **Интерфейсы (абстрактные классы)** — методы без реализации.

4. **Абстракция (Abstraction)**
	**Сокрытие сложности и выделение ключевых особенностей объекта.**
	- Использование абстрактных классов и интерфейсов.
	- Показ только нужных деталей, скрытие лишнего.
