[[Логирование]] - основная информация

в го есть следующие уровни:
```Go
LevelDebug Level = -4
LevelInfo Level = 0
LevelWarn Level = 4
LevelError Level = 8
```
Если выбрать уровень Debug, то будут показываться все уровни логов, если выбрать уровень Info, то будут показываться только info, warn и error и так далее.

пример:
```Go
package main

import (
	"log/slog" // Пакет для логов
	"os"
	
	"github.com/Dashiiidzzze/admin_panel_for_rfid_security/internal/config"
)

// чтобы не использовать текст в прямом виде
const (
	envLocal = "local"
	envDev = "dev"
	envProd = "prod"
)

func main() {
	cfg := config.MustLoad()
	
	// TODO: init logger: slog
	log := stupLogger(cfg.Env)
	log.Info("starting site", slog.String("env", cfg.Env)) // выведем окружение в котором находимся
	log.Debug("Debug messages are enabled")
	
	// TODO: init storage: postgres
	
	// TODO: init router: chi (совместим с net/http), render
	
	// TODO: init server:
}

// инициализация логера slog
func stupLogger(env string) *slog.Logger {
	var log *slog.Logger
	switch env {
	case envLocal: // логгер для локальной разработки и дебага
		log = slog.New(
		slog.NewTextHandler(os.Stdout, &slog.HandlerOptions{Level: slog.LevelDebug}),
		)
	
	case envDev: // логгер для dev окружения
		log = slog.New(
		slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{Level: slog.LevelDebug}),
		)

	case envProd: // логгер для продакшена
		log = slog.New(
		slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{Level: slog.LevelInfo}),
		)
	}
	
	return log
}
```

Пример вывода
```bash
time=2025-04-26T13:35:01.057+07:00 level=INFO msg="starting site" env=local
time=2025-04-26T13:35:01.057+07:00 level=DEBUG msg="Debug messages are enabled"
```
