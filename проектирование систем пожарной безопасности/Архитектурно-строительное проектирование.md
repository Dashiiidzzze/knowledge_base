**архитектурно-строительное проектирование** — это процесс подготовки проектной и рабочей документации для объектов капитального строительства.

Необходимая документация:
- Проектная (стадия П)
- Рабочая (стадия Р)

## Проектная документация 
представляет собой материалы в текстовой и графической формах, а также в форме информационной модели, необходимой для определения архитектурных, функционально-технических, конструктивных и инженерно-технических решений для обеспечения строительства, реконструкции, капитального ремонта.

**Нужна для:** определения основных технических решений и прохождения экспертизы.

Не нужна для ИЖС и садовых домов, если не нужна экспертиза

#### Процесс начала работ 
условно можно представить так: заказчик собирает необходимые исходные данные или разрабатывает их совместно с проектировщиком, заключает договор…

Передаёт комплект документов проектировщику. В свою очередь, Градостроительный кодекс устанавливает список документов, которые заказчик обязан передать специалистам по разработке проектной документации. 
##### Документы - основание для начала проектных работ: 
- градостроительный план земельного участка (нам не нужен)
- Результаты инженерных изысканий или задания на их выполнение
- Технические условия подключения объектом к сетям инженерно-технического обследования (это могут быть технические условия для реализации оповещения систем ГО ИЧ или для передачи данных на удалённую станцию пожарного мониторинга)
- Задание заказчика на проектирование. В данном документе содержатся необходимые сведения об объекте строительства, разрабатываемых системах.
## Рабочая документация
представляет собой материалы в текстовой, графической формах, а также в форме информационной модели, необходимой для осуществления строительства и реконструкции. Рабочая документация разрабатывается на основании проектной, а также подготовка проектной и рабочей документации может происходить одновременно.

**Нужна для:** ведения строительно-монтажных работ.
