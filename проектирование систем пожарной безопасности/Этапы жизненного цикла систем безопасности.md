**Примерный жизненный цикл:**
- **проведение инженерных изысканий** для разработки проектной документации систем, сбор исходных данных для составления задания на проектирование (задания на разработку СТУ);
- **разработка задания на проектирование;**
- **проектирование;**
- строительно-монтажные работы;
- пусконаладочные работы;
- опытная эксплуатация, комплексное опробование и ввод в эксплуатацию;
- **авторский надзор;**
- эксплуатация, техническое (сервисное) обслуживание и текущий ремонт;
- вывод из эксплуатации, демонтаж и утилизация.

 **проведение инженерных изысканий**:
- формирование (сбор) исходных данных из общего объема информации по результатам инженерных изысканий для разработки проектной документации систем;
- выборка необходимых данных из общего объема архитектурно-планировочных и технологических проектных решений;
- обследование объекта: анализ ранее разработанной проектной документации, изучение существующих систем и сбор иных данных, необходимых для разработки проектной документации;
- анализ ранее составленных актов проверки и предписаний надзорных органов;
- определение достаточности существующей нормативно-правовой базы и необходимости разработки СТУ;
- составление технического отчета по итогам инженерных изысканий для разработки проектной документации систем

**разработка задания на проектирование:**
- формирование (сбор) исходных данных для построения систем;
- составление перечня документов, образующих нормативно-правовую базу для построения конкретной системы;
- формулирование назначения систем, целей их создания и решаемых задач. Формирование перечня потенциальных внешних и внутренних угроз и вероятных причин их возникновения;
- формулирование особых условий назначения, строительства (реконструкции) и последующей эксплуатации объекта
- (систем);
- разработка задания на проектирование, в том числе формулирование требований к сметной документации;
- согласование задания на проектирование;
- утверждение задания на проектирование
